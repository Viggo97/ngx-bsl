Pagination

Pagination component allows to set current page by [page] input, total amount of items by [total] input and number of items per page by [size] input. Additionally, it supports the following inputs to set aria- values in different languages: nextPageAriaLabel, previousPageAriaLabel, firstPageAriaLabel, lastPageAriaLabel, selectPageAriaLabel and selectPageAriaLabelledBy. Components emits pageChanged event with current page value.
