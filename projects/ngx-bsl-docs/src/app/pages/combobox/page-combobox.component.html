Combobox

Combobox enables users to enter a value or choose one from a dropdown. Options are provided by using ng-content with dedicated components such ngx-bsl-list-box-option, ngx-bsl-list-box-group or ngx-bsl-list-box-separator. Options can be changed dynamically - the implementation is up to user. The output value is always of type string, but options can be either string or complex objects.
